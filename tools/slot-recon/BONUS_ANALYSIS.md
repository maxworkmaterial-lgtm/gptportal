**Правила, которые вытекают из замеров:**
1. **Бонус громче базы в среднем на 4.5 LU** (от +1.6 до +12). База — фон, бонус — сцена.
2. **Бонус плотнее:** LRA падает (Laced 4.0 → 1.6). Музыку сжимают, она «давит» ровно.
3. **Темп меняется резко: удвоение или half-time.** Black Friday и Brainwashed ускоряются вдвое (драйв, погоня). Laced, Nuukd и Love Nest уходят в half-time (тяжесть, «трип», хоррор). Главное — смена ощущения, а не просто «быстрее».
4. **Музыка = уровень.** У Trap Tower 4 версии трека бонуса, каждая громче и ярче (яркость спектра 944 → 1227 Гц). Игрок слышит прогресс, даже не глядя на шкалу.
5. **Персонализированная музыка.** У Mortal Bromance отдельный трек на каждую пару бойцов.

### 5.2. Big win: громкость кульминации

- Стингеры big win играют на −9…−14 LUFS, то есть **на 8–15 LU громче базы**. Это самый громкий звук игры.
- Почти везде 4 уровня по 4.5–6 с плюс отдельный финал (`Bigwin_lvl_end`, `Bigwin_lvl4_end`). 4-й уровень длинный (11–13 с) и зациклен: «праздник длится».
- Отдельный звук **смены уровня** (`Bigwin_lvl_change_boom` в Truth). Удар между ступенями — главный момент дофамина.
- Счётчик суммы — отдельный луп (`Win_number_counter` / `Bigwin_count`) с высокой яркостью (1900–2800 Гц), плюс финальный «щелчок» (`Win_counter_end`, `coin_win_slam`).

## 6. Дофаминовые механики (что именно подсаживает)

1. **Мгновенный вход после оплаты.** Нажал BUY — меньше чем через секунду идёт сплэш. Нет паузы, чтобы передумать.
2. **«Click to continue» = иллюзия контроля.** Игрок сам «запускает» бонус, хотя исход уже посчитан сервером.
3. **Два встречных счётчика.** Спины ↓ и множитель/шкала/уровень ↑. Чем меньше спинов, тем выше ставка каждого: напряжение растёт к концу.
4. **Накопление без сброса.** Множитель, шкала и уровень сохраняются между спинами: «я уже вложился в этот бонус».
5. **Ретриггер +3 спина.** Внезапное продление в момент, когда бонус почти закончился.
6. **Near-miss в бонусе.** Замки на позициях (Truth), почти полная сетка (Office Party), босс «KAREN INCOMING!» со 100x.
7. **Ступенчатый big win громче всего остального.** Даже 16x на покупке за 85 празднуется (LDW, раздел 2).
8. **Сюжетная концовка.** Эпилог Suck при выигрыше 2.25 из 79 — это закрытая история, а не «ты проиграл». Хочется следующую серию.
9. **Контраст при возврате.** После красного ада, неона и громкой музыки база выглядит пустой и тихой. Магазин ($) всегда на экране.
10. **Рандом внутри платного продукта.** Enhanced Bonus «1–3 звезды», Loot Box, Highlight Reels — лотерея внутри лотереи.

## 7. Технический разбор

### 7.1. Сервер решает всё за один вызов

`POST /game/play {action: "FEATURE_BUY" | "FEATURE_BUY_SUPER", bet}` → `wager.win` + `wager.data[]`, где каждый элемент — один шаг (спин) бонуса.
Клиент только проигрывает шаги; `POST /game/complete` закрывает раунд.

Состояния шагов: `basegame > freespin`, у части игр есть ещё `respin` (Black Friday, Suck, Office Party).
Помимо стандартных полей (`reels`, `moneyWon`, `accumulatedWin`, `isFSTrigger`, `freeSpinsLeft`), каждая игра добавляет поля своей фичи:

| Игра | Поля фичи бонуса |
|---|---|
| Black Friday | `carnage`, `coinsCollected`, `totCoins`, `removedSymbolsCoords` |
| Brainwashed | `dragons`, `accDragonCount`, `goldenDragonWinCount`, `trapCoordinates`, `symbolTransformations` |
| Devil's Finger | `fingerLevels`, `spells`, `reelsMultiplier`, `reelsExtraMultiplier`, `extraSpins` |
| Love Nest | `globalMultiplier`, `boxData`, `finalBoxData`, `isBoxDropSpin`, `featureEvents` |
| Nuukd | `mysteryStacks`, `scatterCount` |
| Office Party | `levelReached`, `pinataPopped`, `weaponMultipliers`, `usedWeapons`, `coinsCollected` |
| Oops | `feature` |
| Orphan Organ | `metersConfig`, `blackholesConfig`, `scatterMeterWins`, `extraFreeSpins` |
| Preach TV | `donations`, `donationMoneyWon`, `gateFeatures`, `wildStacks`, `lowToHigh`, `isSuperFreespin` |
| SEW | `hotZones`, `upgradeLevel`, `isLevelUp`, `coinWins`, `transformedSymbols` |
| Sheeple | `positionMultipliers`, `sheepleFeature` |
| Suck | `bonusDetails`, `lockedWin`, `mysteryFeature`, `scatterWins` |
| Swoll | `swollDetails`, `bonusType` |
| Trap Tower | `level`, `finalLevel`, `loot`, `finalLoot`, `hotZones`, `hotZoneRewards`, `multiGrid`, `symbolTransformationChains`, `preStopFeatureEvents` |
| Truth | `truthRealmMultiplier`, `truthRealmWin`, `stickyConfig`, `nudgeFeature`, `funFeatures`, `mysterySymbol` |

**Вывод для архитектуры:** математика отдаёт «книгу» шагов (как book events в Stake Engine), а фронт — это режиссёр, который превращает каждое поле в анимацию и звук.
Чем богаче поля шага, тем больше поводов для эффектов. Trap Tower отдаёт даже `preStopFeatureEvents`: события до остановки барабанов, специально под анимацию.

### 7.2. Анимации (Spine 4.2): структура бонуса

| Элемент | Типичные анимации | Длительности |
|---|---|---|
| Сплэш входа | `Intro/Start` → `Intro/Idle` (ждёт клика) → `Intro/End` | 1.6–5.3 / ∞ / 0.4–1.7 с |
| Фон | `toFreespins`, `freespins` (скин) | 0.67 с — стандарт студии |
| Длинный переход | `transition_1/2` (Black Friday), `transition` (Office Party) | 6.7–8 с |
| Уровни в бонусе | `freespin-2/3/4` + `-loop` + `-out` (Trap Tower), `FStransitions/1–5` (Oops), `level/1–6/max` (SEW), `meterLevel/0–8` (Orphan Organ) | ~1–2.5 с на смену |
| Персонаж | Отдельный скелет на бонус: `free_spins/idle` 16–37 с (Preach TV, Laced), `dancer/win_level_0–5` (Office Party) | длинные лупы |
| Предвкушение | `anticipation/start/idle/end`, `bonus/activate` | 0.3–1.1 с |
| Выход | `Outro/Start/Idle/End`, `bonusOutro` 5–7.7 с, `freespin-to-basegame-loop` до 6.7 с | |
| Big win | `bigwin` уровни 1–4 + end, `maxwin` + `maxwinbg` | синхронно со звуком |

**Стандарт студии:** смена скина фона 0.67 с, сплэш с бесконечным idle до клика, у каждого уровня эскалации своя анимация входа, лупа и выхода.

### 7.3. Магазин (store)

Одна и та же canvas-витрина во всех играх, 3 версии раскладки. Внутри: Bonus Boost, Feature Booster, Bonus / Super Bonus, Enhanced Bonus (Bronze/Silver/Gold), Highlight Reels, Loot Box.
Цена бонуса на €1 ставки — 67–103, супербонус — 272–482, Gold Enhanced — до 1596.

## 8. Что берём в свой слот (ТЗ-уровень)

### Ограничения рынков (учитывать сразу)

Правила UKGC: в Великобритании покупка бонуса запрещена с 2019 года; с 2021 года нельзя праздновать выигрыш, который не больше ставки, и нельзя turbo/autoplay.
Значит, нужен флаг юрисдикции, который отключает Store и «празднование» LDW. RGS Shady Lady уже отдаёт `jurisdiction` в `/authenticate`.
