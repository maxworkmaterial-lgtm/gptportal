# Стайлгайд: InOut × Shady Lady (30.10.2026)

Источник: живые экраны 8 игр InOut (Megablock Empire, Dragon Pots, Joker Pyre, Aztec Totem, KO Million, Rump & Friends, Ballonix, Wheel Out) и 18 игр Shady Lady (базовая игра, сплэши, бонуски).
Правило: **игра для InOut**. UI, раскладка, интро-экран и монетизация берутся из их кита. От Shady Lady берём только рисовку, сатиру и драматургию бонуса.

---

## 1. UI kit InOut (обязателен)

### Нижняя панель (одинаковая во всех играх)
Тёмная скруглённая плашка по центру снизу, ширина около 80% экрана. В ней ячейки слева направо:

| Ячейка | Вид |
|---|---|
| **BUY BONUS** | Золотая плитка с иконкой монеты, тёмно-золотой фон, золотая обводка. Стоит первой слева |
| **BALANCE** | Подпись капсом мелким серым, значение белым жирным с иконкой монеты `$` в кружке |
| **WIN** / **MULTIPLIER** | Так же |
| **DIFFICULTY** / **SPEED** | Значение + шевроны ▲▼ справа |
| **CASHOUT** / **PART CASHOUT** | Серый текст, пока неактивна |
| **BET** | Значение + шевроны ▲▼ |
| **PLAY** | Круглая зелёная глянцевая кнопка с белым треугольником, выступает за панель, тёмное кольцо вокруг |
| **Autoplay** | Иконка из двух круговых стрелок в отдельной ячейке справа |

Цвета, снятые пипеткой с Megablock:

| Токен | Цвет |
|---|---|
| Фон панели | `#1F1D1E` |
| Фон ячейки | `#27272C` |
| Обводка ячейки | `#333337` |
| Подпись (label) | `#5F5F63` |
| PLAY, свет | `#3BD369` |
| PLAY, тень | `#1F834A` |
| BUY BONUS, золото | `#E0A41B`, обводка `#C19700` |

Шрифт UI: гротеск без засечек (Roboto/Inter-подобный), подписи капсом 11–12 px, значения 14–16 px bold.

### Остальной экран
- **Лого** слева сверху: объёмное «мультяшное» лого с толстой обводкой и цветным градиентом.
- **Live wins / Online: 14 336**: тикер под лого, зелёная точка. Это социальное доказательство.
- **Меню**: круглая полупрозрачная кнопка-гамбургер справа сверху.
- **Интро-экран правил** (Dragon Pots, Joker Pyre, Rump): иллюстрация фичи в рамке, 1–2 строки белого текста, большая зелёная кнопка **PLAY**, точки пагинации, «Don't show again».
- **Джекпот-плашки** GRAND / MAJOR / MINOR / MINI: цветные плитки (золото / фиолет / синий / зелёный) с портретом персонажа и `x2000…x20`.
- **Таблица множителей / лестница** (Aztec Totem, Megablock): цветные полосы со стрелками `3.9x > 12.5x > … > BONUS`.
- **Уведомления**: красный тост справа сверху («Login Required»).

### Рисовка InOut
Яркий казуальный мобильный мультфильм: чистый вектор с мягким объёмом, насыщенные цвета, дневной свет, дружелюбные персонажи.
Сатира у InOut **уже есть**: Rump & Friends (пародия на Трампа), KO Million (боксёр), Wheel Out (индийский комедийный сеттинг). Значит, острая тема в духе Shady Lady им подходит, если упакована в их кит.
Механика у части портфеля общая: **сбор монет / Hold & Win** (Joker Pyre, Rump, Dragon Pots, Chicken Coin). На этой же механике сделан SlotEngine (Pharaoh's Fortune).

## 2. Рисовка Shady Lady (что берём)

| Элемент | Как у них |
|---|---|
| Персонажи | Гротескная карикатура: огромные головы и руки, вены, складки, красная кожа от злости (Pissed), фольгированные шапки и пришельцы (Truth). Полу-реалистичный рендер с толстым контуром, детальная фактура кожи |
| Сплэш | Персонаж крупно по центру на радиальном взрыве цвета, вокруг разлетаются предметы-панчлайны и рукописные фразы («You can't say that anymore…», «Use paper straws!»), лого хромом с подтёками. Внизу «Click anywhere to continue» |
| Символы | Портреты персонажей в карточках с цветной шапкой-окошком (`_□×`, как окно ОС, у Truth), предметы темы с жирной обводкой |
| Фон | Детальная захламлённая сцена-комната (полки, постеры, предметы-шутки), приглушённая, не спорит с барабанами |
| Цвет | Грязная приглушённая база + один кислотный акцент на игру (красный Pissed, зелёный Truth, неон Black Friday) |
| UI у них | Круглые тёмные кнопки (кубок, звук, меню), большая круглая кнопка спина справа, неоновый `$`-магазин. **Это не берём**: у нас кит InOut |

### Главные референсы (выбраны Максом)

**Магазин (Nuukd).** Тёмные панели категорий: MOST POPULAR, BOOSTERS, BONUS, HIGHLIGHT REELS, LOOT BOX. У каждой категории **свой персонаж-маскот**: бюст мутанта слева (морж с мозгом, лис-шахтёр, рогатый с бочкой, рыбочеловек, младенец в колбе). Заголовки — жёлтая иконка + узкий жирный шрифт капсом (Anton-подобный), под ними строка пояснения. Товары — **белые квадратные карточки с чёрными иконками-штампами**: «BONUS», «SUPER BONUS», «BIG BONUS BOOST», «MAX», «TOP3/100», значки BRONZE/SILVER/GOLD с цветной заливкой. Цена — под иконкой.

**Бонус Sheeple.** Символы — **цветные карточки по персонажу**: жёлтый, синий, красный фон. Гигантские слитые символы 2×1 и 2×2. Множитель — бейдж-сердечко в углу карточки. Счётчик ways на деревянной табличке («6300 ways»). Счётчик спинов нарисован на овечьей шкуре («4»). Фон — розовая вечеринка с лепестками. Активный Gold Bonus горит жёлтым значком. Кнопка FAST FWD — овальная пилюля.

**Сплэш Swoll.** Экстремальный крупный план: грудь качка, татуировка орла, золотая цепь, след помады. **Лого сделано из материала темы**: буквы из мышц и вен, с каплями пота. Кадр — персонаж, а не интерфейс.

**База Swoll.** Рамка барабанов — силовая рама из перфорированной стали. **Карточки персонажей оформлены как посты в соцсети**: лайк, коммент, шер и фейковые комментарии на карточке. Низкие символы — предметы темы (леопардовые стринги, масло для загара, стакан сырых яиц, стейк). Скаттер — банка протеина SWOL MAXXX в розово-золотой рамке. Вайлд — энергетик. Названия фич (NUDGE, SLIDE) написаны ретро-аркадными буквами. Фон — качалка с ламбо и коробкой «ROIDS».

**Что из этого следует для нас:**
- **Маскот на каждую категорию** покупки переносим в BUY BONUS меню InOut: их панель, а внутри персонажи нашей темы.
- **Иконки-штампы** на белых карточках дают продуктам узнаваемость. Делаем свой набор штампов.
- **Цветная карточка на персонажа** и слитые гигантские символы — стандарт читаемости.
- **Лого из материала темы**, а не просто шрифт с обводкой.
- **Счётчики нарисованы предметами темы** (табличка, шкура), а не цифрами в UI.
- Swoll уже обыгрывает тему «качки × соцсети». Если наша тема тоже про инфлюенсеров, **нельзя повторять приём «карточка-пост»**: нужен свой ход.

## 3. Наш гибрид: правила

1. **Каркас = InOut.** Нижняя панель, лого, Live wins, гамбургер, интро-экран, джекпот-плашки и BUY BONUS — по киту InOut. Не меняем ни размеры, ни цвета токенов.
2. **Рисовка = мост между ними.** Берём читаемость и яркость InOut (свет, насыщенность, чистые силуэты для мобилки) и добавляем характер Shady Lady: гротескные пропорции, толстый контур, фактура, сатира. Мрак и грязь только в бонусе.
3. **База светлая, бонус тёмный.** Базовая игра в дневной палитре InOut. Бонус меняет мир на ночь/неон/красный — как у Shady Lady (смена мира из BONUS_ANALYSIS.md).
4. **Символы** читаются на телефоне 64 px: портрет персонажа в карточке + один цвет-код на персонажа.
5. **Лого** в стиле InOut (объём, толстая обводка, градиент), но шрифт и предмет из темы.
6. **Без мата и токсичных надписей на экране.** У Shady Lady есть «F*CK OFF!», у InOut в портфеле такого нет: оператору важнее безопасность.
